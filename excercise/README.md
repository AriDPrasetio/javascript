# Exercises

Folder ini berisi latihan untuk mempraktikkan contoh kode dari materi di folder
[`docs`](../docs/). Latihan disusun mengikuti urutan fase pembelajaran
JavaScript.

## Tujuan

- Menulis ulang contoh kode agar lebih terbiasa dengan sintaks JavaScript.
- Memahami cara kerja kode melalui percobaan langsung.
- Mengembangkan contoh dari materi dengan perubahan kecil.

## Struktur Folder

- [`1-introduction`](./1-introduction/) — pengenalan JavaScript dan cara menjalankannya.
- [`2-syntax-data-types-and-operators`](./2-syntax-data-types-and-operators/) — sintaks, tipe data, dan operator.
- [`3-variables-and-scope`](./3-variables-and-scope/) — variabel dan scope.

## Cara Menggunakan

1. Baca materi yang sesuai di folder [`docs`](../docs/).
2. Buka folder latihan dengan nomor fase yang sama.
3. Tulis dan ubah contoh kode di dalam folder tersebut.
4. Jalankan kode, lalu amati hasilnya melalui browser atau Node.js sesuai kebutuhan.

Latihan akan ditambahkan secara bertahap seiring bertambahnya materi.
